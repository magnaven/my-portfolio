**GSAP animation inside useGSAP:**
Use `gsap.matchMedia()` with a single `mm.add()` call wrapping the entire sequence. Pattern from RESEARCH.md Pattern 1:

```typescript
useGSAP(() => {
  const mm = gsap.matchMedia();
  mm.add(
    { reduceMotion: "(prefers-reduced-motion: reduce)" },
    (context) => {
      const { reduceMotion } = context.conditions!;

      if (reduceMotion) {
        gsap.set(
          [headlineRef.current, ".credential-line", ".cta-group", ".scroll-indicator"],
          { autoAlpha: 1, y: 0 }
        );
        return;
      }

      const split = SplitText.create(headlineRef.current, {
        type: "chars",
        tag: "span",
      });

      const tl = gsap.timeline();

      tl.from(split.chars, {
        autoAlpha: 0,
        y: 40,
        duration: 0.45,
        stagger: 0.018,
        ease: "back.out(1.4)",
      })
      .from(".credential-line", {
        autoAlpha: 0,
        y: 16,
        duration: 0.4,
        ease: "power2.out",
      }, "-=0.1")
      .from(".cta-group", {
        autoAlpha: 0,
        y: 14,
        duration: 0.35,
        ease: "power2.out",
      }, "-=0.1")
      .from(".scroll-indicator", {
        autoAlpha: 0,
        y: 8,
        duration: 0.3,
        ease: "power2.out",
      }, "-=0.05");
    }
  );
}, { scope: containerRef });
```

**Scroll indicator bounce animation** (separate `useGSAP` call, also inside matchMedia reduceMotion guard):
After the load sequence, the scroll indicator should bounce with a continuous `gsap.to()` yoyo loop on `y: 6`. Only run when `!reduceMotion`. Add a `useEffect` that sets indicator to `autoAlpha: 0` when `window.scrollY > 50` (using passive scroll listener) so it fades out once the visitor starts scrolling.
