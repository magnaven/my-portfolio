From components/NavBar.tsx (existing Phase 2 code):
The component uses a `scrolled` boolean state that starts as `false`, then a `useEffect` with a scroll listener sets it to `true` when `window.scrollY > 90`. The background class switches between transparent and `bg-canvas` based on `scrolled`.

Target modification (from RESEARCH.md Pattern 4 — usePathname approach):
```typescript
// Add at top of component (inside the function, before existing state):
import { usePathname } from "next/navigation";

const pathname = usePathname();
const alwaysSolid = pathname.startsWith("/work/");

// In the existing useEffect that sets scrolled:
// Change the initial setScrolled call and the scroll handler to:
useEffect(() => {
  setScrolled(alwaysSolid || window.scrollY > 90);
  const handleScroll = () => setScrolled(alwaysSolid || window.scrollY > 90);
  window.addEventListener("scroll", handleScroll);
  return () => window.removeEventListener("scroll", handleScroll);
}, [alwaysSolid]);
```

This is a surgical two-line change to the existing useEffect — do not rewrite the whole component.
